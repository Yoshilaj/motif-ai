編集のすべてが、ひとつのアプリに。

  1. 素材を入れる
  2. 何をつくるか書く
  3. 話しかけて直す
  4. 書き出す

  • 言い直しも自動でカット

    2つの音声認識モデルで、無音・言い直し・言いよどみを見つけて切ります。

  • 日本語テロップ

    話した言葉をテロップに。強調や色もスタイルどおり。固有名詞は辞書で正しく。

  • モーショングラフィックス

    見出し・図解・リストを、話している内容に合わせて入れます。

  • BGM と効果音

    内蔵のライブラリから選び、間とタイミングを合わせます。

  • 色の補正

    暗い・くすんだ映像も、自動補正や LUT で見やすく整えます。

  • 人物の切り抜き

    人物の後ろに文字を置く演出も。切り抜きは Mac の中で行います。

  • 写真と Web ページ

    話に出てきた場所やサービスの写真・画面を、ライセンスの処理ごと入れます。

  • 手で直せるタイムライン

    AI の編集はすべてクリップとして残り、一つずつ手で調整できます。

よくある質問

そのほかのご質問は support@motif-ai.app まで。

どんな人に向いていますか？

事業やチャンネルのために動画を出し続けたいのに、編集に時間を取られている方に向いています。話す動画（リール・ショート・YouTube の解説など）が得意です。

編集の経験がなくても使えますか？

はい。何をつくりたいかを日本語で書くだけで編集が進みます。細かい調整もチャットで頼めますし、タイムラインで手で直すこともできます。

AI が編集したあと、自分で直せますか？

はい。カット・テロップ・グラフィックはすべてタイムライン上のクリップとして残るので、一つずつ手で調整できます。

Claude や ChatGPT のプランが必要なのはなぜですか？

Motif の AI は、お持ちの Claude または ChatGPT のアカウントで動きます。そのため Motif の料金に AI の使用量の上限はなく、各社のプランの範囲内で無制限にお使いいただけます。

動画はどこに保存されますか？

素材とプロジェクトはお使いの Mac に保存され、Motif のサーバーにはアップロードされません。文字起こしも Mac の中で行います。編集の指示や確認に必要な文字と画像は、お使いの AI（Claude または ChatGPT）に送られます。

Windows や iPhone で使えますか？

現在は、Apple シリコン搭載の Mac（macOS 13 以降）でお使いいただけます。

無料トライアルのあと、自動で課金されますか？

されません。カードの登録は不要です。トライアルが終わると、チャット・AI の機能・新しいスタイルの作成が止まります。プロジェクトを開く・手で編集する・書き出すことは、そのまま続けられます。

解約や返金はどうなりますか？

Motif の 設定 › プラン からいつでも解約でき、お支払い済みの期間の終わりまでお使いいただけます。返金については返金ポリシーをご覧ください。

Premiere Pro など、ほかのソフトに持っていけますか？

はい。MP4 での書き出しのほか、Premiere Pro などで開ける XML 形式でタイムラインを書き出せます。
